# نص الفيديو التوضيحي — دقيقتان كحد أقصى

التسجيل: شاشة المتصفح على الرابط المباشر + تعليق صوتي. لا شرائح إلا الأولى والأخيرة.
اكتب الأرقام من `eval/results/results.md` وقت التسجيل؛ المواضع المعلَّمة بـ ⟨ ⟩ تُملأ منه.

| الثانية | الصورة | التعليق الصوتي |
|---|---|---|
| 0:00–0:12 | شعار تبيّن والعبارة «تحقّق قبل أن تصدّق أو تنشر» | كم مرة سمعت حديثاً في مقطع قصير وتساءلت: هل هذا صحيح؟ التحقق اليدوي يأخذ دقائق لكل استشهاد، فيُترك، وينتشر الخطأ. |
| 0:12–0:35 | الصق مثال «نص فيه آية وحديث» ← اضغط «تحقّق» ← تظهر البطاقات واحدة تلو الأخرى | تبيّن يستخرج كل استشهاد، ويطابقه مع المصادر المعتمدة. الآية تُطابَق خوارزمياً مع نص المصحف، والحديث يُعرض بنصه في المصدر وحكم المحدّثين منقولاً حرفياً. |
| 0:35–0:55 | افتح بطاقة الحديث: النص الأصلي، الفروق، الحكم واسم المحدّث، رابط المصدر | كل «مؤيَّد» يحمل نص المصدر ومرجعه ورابطه. لا حكم بلا مصدر. |
| 0:55–1:15 | تبويب «رابط مقطع» ← رابط يوتيوب ← التفريغ بالطوابع الزمنية ← اضغط على استشهاد فينتقل إلى بطاقته | الصق رابط مقطع: يفرّغه، ويحدد الدقيقة التي ورد فيها كل استشهاد. |
| 1:15–1:35 | مثال «طلب اختلاق حديث» ← البطاقة الحمراء مع الآية وزر «إحالة إلى أهل العلم» | وحين لا يجد مصدراً، يمتنع صراحة ولا يؤلف بديلاً. والمسائل الخلافية والحالات الشخصية تُحال إلى أهل العلم. |
| 1:35–1:50 | الرسم البياني للمقارنة | على ⟨عدد⟩ ادعاءً، بلغت دقة تبيّن ⟨٪⟩ مقابل ⟨٪⟩ للبحث اللفظي و⟨٪⟩ لروبوت محادثة عام — بصفر إسناد مختلَق. |
| 1:50–2:00 | الشعار + الرابط المباشر + رابط المستودع | تبيّن: أداة مفتوحة المصدر، مدعومة بالذكاء الاصطناعي، لا تغني عن الرجوع إلى أهل العلم. |

## ملاحظات التسجيل

- سجّل العرض الحي مرة واحدة متصلة ثم اقطع؛ لا تركّب نتائج لم تظهر فعلاً.
- إن كان رقم روبوت المحادثة العام لم يُقَس بعد، احذف جملته ولا تقدّره.
- أظهر سطر الشفافية أعلى الصفحة في لقطة واحدة على الأقل.
- المدة القصوى دقيقتان (شرط دليل المشارك).
