# نصوص التسجيل الصوتي

عشرون نصاً قصيراً مولَّدة آلياً من مجموعة الاختبار (`eval/testset/claims.jsonl`) لتُسجَّل بأصوات الفريق.

- اقرأ كل نص كما هو، حتى إن تضمّن خطأً مقصوداً (آية غُيّر لفظها، حديث ضعيف أو موضوع): الغرض اختبار الأداة.
- احفظ التسجيل باسم الملف المذكور في `manifest.json` (مثل `01.m4a`) داخل هذا المجلد.
- بعد التسجيل ارفع الملف في تبويب «رفع ملف» وقارن النتيجة بالحالة المتوقعة في `manifest.json`.
- النصوص الشرعية هنا منقولة برمجياً من المصادر المعتمدة، والنصوص المعيبة مولَّدة آلياً؛ كلها تنتظر مراجعة سليمان.
